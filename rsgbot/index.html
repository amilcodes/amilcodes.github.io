What is RSGbot?

An agent that plays Minecraft from screenshots. A vision-language model checks the scene, inventory, and route notes, chooses a few actions, then looks again.

Goal

Finish a new Minecraft world: tools → portal → Nether resources → stronghold → dragon.

Random Seed Glitchless: a random world, without glitches.
What we built

A Python agent for perception, memory, and keyboard/mouse control; a Java practice client for frame capture, input, and separate scoring.
