# Amil Agrawal

Personal portfolio at https://amilagrawal.com/. GitHub Pages publishes the root of `main`; `CNAME` retains the custom domain. `.nojekyll` serves the files directly.

The homepage uses buildless HTML, CSS, and JavaScript. Its media and fonts are self-hosted in `assets/`. Keep the existing `rsgbot/` project page and its files when updating the homepage.

Preview locally with `python3 -m http.server 8765`.
